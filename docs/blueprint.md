# **App Name**: Tezfo Access

## Core Features:

- Single File Login: Implement a login system within a single HTML file using HTML and CSS, and role-based access.
- Role Management: Assign roles (e.g., admin, user) with corresponding access permissions to different parts of the GymDesk.
- Basic GymDesk UI: Simple UI displaying the features based on the user's roles.

## Style Guidelines:

- Primary color: Deep blue (#3F51B5) to convey trust and professionalism.
- Background color: Very light blue (#E8EAF6), almost white, providing a clean and unobtrusive background.
- Accent color: Vibrant orange (#FF5722) to highlight key actions and elements, contrasting well with the primary blue.
- Font: 'Inter' (sans-serif) for a modern, clean and highly readable user interface. Use 'Inter' for both headlines and body text.
- Use a set of modern icons representing gym related activity.
- Clean and straightforward layout using a single page.
- Subtle animations for user feedback when a user logs in.
